# Trove Homebrew Tap

Install [Trove](https://gettrove.vercel.app/), the local all-in-one Mac utility:

```sh
brew tap arnavgoel03/trove
brew install --cask trove
```

Updates after install are delivered in-app (Sparkle). The app is not yet
Apple-notarized, so on first launch you may need to approve it in
System Settings > Privacy & Security.
